# 图书馆比例校准（2026-10-09）

依据用户提供的正面全景截图 `user-front.png` 校准相对比例。图片带透视与全景投影，不能作为实测图纸；下列模型尺寸都是估算。

- 塔楼提高至约45.9米屋顶高度，修正过深的后退距离，使主体下部不再被裙楼大量遮挡。正面保留五道宽窗带、两道窄边窗，补顶部大窗与水平分隔。
- 两翼基座与入口标高同步，改为平屋顶裙楼；扩大中央拱窗、两侧矩形窗，入口调整为七个开间。
- 台阶从等宽改为下宽上窄，宽度依次为68、54、40米；两侧花坛分三层向内收进。
- 入口标高仍为4.36米，28级、15厘米踏步仍是此前估算，没有把照片作为真实级数或绝对高度证明。
- 同步修改行走高度范围、两翼墙体和花坛碰撞、NPC路线，避免人物在收窄后的楼梯外侧悬空。
