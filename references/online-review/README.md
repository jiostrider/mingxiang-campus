## 代码与验证

楼梯尺寸与行走高度集中在 `src/library-entrance.js`。
人物与NPC共用场景高度；水体外观与水岸碰撞共用岸线。
`node tests/south-plaza.mjs` 检查台阶上行、休息平台、跳跃、下行、NPC脚高、旗杆绕行、门房通道、骑行与画质。
`node tests/browser.mjs` 检查原有漫游功能。
截图在 `artifacts/south-plaza/`，其中 `08-library-stairs.png` 为入口近景。

本轮两套浏览器检查通过：上楼后人物位置约 `(0,4.36,59.55)`，下楼回到广场 `y=0.16`，湖岸阻挡正常，浏览器错误为0。画面仍采用现有程序化模型，材质、植被与人物精度还未达到GTA5式写实目标。
