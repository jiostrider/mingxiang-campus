# 图书馆南侧广场参考与实现记录

本轮依据用户于 2026-10-08 提供的四张照片和 2.57 秒视频细化。
视频为图书馆正面与广场边缘；照片提供钟塔、三根旗杆、球形灯、
有支撑杆的幼树、常绿树与两侧低层建筑的参考。

源码入口：`src/south-plaza.js`；图书馆立面与台阶：`src/world.js`。

已落实：开阔广场、粗颗粒浅褐铺装、四条宽深色横带、边缘排水口、
长椅、六球景观灯、钟塔、三根旗杆与旗面动画、分层绿化、连续台阶、
拱形门窗、主楼竖向窗带及砂岩墙面接缝。小地图同步场景布局。

重建尺寸、横带间距、钟塔与旗杆的具体坐标仍为照片推估，
需要平面图或测量资料进一步校准。左右侧旗面颜色取自照片的大致色彩，
未臆造校徽和文字。现有 Blender 文件是此前导出快照，网页以源码为准。

2026-10-08 再次根据学校官网实景核查：提高图书馆台阶和入口平台，
增加中间平台并同步人物/NPC地面高度；调整中轴旗杆、钟楼、校史馆、
南门与湖区。来源、已修正项目和未确定尺寸见 `../online-review/README.md`。

验证与截图：`node tests/south-plaza.mjs`，输出在 `artifacts/south-plaza/`。
视频取帧：`node tests/review-reference.mjs`。
运行：`node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173 --strictPort`。
构建：`node node_modules/vite/bin/vite.js build`。
